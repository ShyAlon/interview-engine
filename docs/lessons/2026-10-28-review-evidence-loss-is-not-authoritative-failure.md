# Review evidence loss is not authoritative failure

Shadow comparison and question verification logs are auxiliary evidence. A write
failure must not change the authoritative interview result, but swallowing it
silently hides what an operator needs. Warn once per sink instance, safe source
code and exception class only. StopRequested is control flow and still propagates.
The full-service root warning handler provides restart-readable evidence; no
service dependency or DB write is introduced into the engine.
